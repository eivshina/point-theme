# Katya Ivshina Portfolio Website

A modern, responsive portfolio website for Katya Ivshina, featuring:

## Features
- Responsive design that works on all devices
- Smooth animations and interactive elements
- Modern typography with Inter and Dancing Script fonts
- Dark theme with orange accent colors
- Optimized images and performance

## Structure
- `index.html` - Main HTML file
- `style.css` - All styling and responsive design
- `script.js` - Interactive animations and functionality
- `assets/images/` - All image assets

## Deployment
This website is ready for deployment on:
- Netlify (drag and drop the entire folder)
- GitHub Pages (upload to repository)
- Any static hosting service

## Local Development
To run locally:
1. Open terminal in project directory
2. Run: `python3 -m http.server 8000`
3. Open browser to `http://localhost:8000`

## Technologies Used
- HTML5
- CSS3 (Grid, Flexbox, Animations)
- Vanilla JavaScript
- Google Fonts (Inter, Dancing Script)

Built with attention to detail to match the original design while showcasing Katya's unique story and achievements.
